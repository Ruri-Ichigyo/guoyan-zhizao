# 项目规范文档归档

本目录包含项目开发过程中的所有规范文档和设计文档。

## 目录结构

- `ai-api-mcp/` - AI 助手与 MCP 功能模块的规范文档
- `fruit-vegetable-recognition/` - 果蔬识别核心功能的规范文档
- `constitution.md` - 项目宪章，定义了项目的核心原则和标准

## 文档说明

这些文档记录了项目从需求分析、架构设计到实现计划的完整过程，包括：

- **spec.md**: 功能规格说明书，定义了功能需求和非功能需求
- **plan.md**: 实现计划，包含架构设计和技术方案
- **tasks.md**: 任务分解，将功能分解为可执行的开发任务
- **research.md**: 技术调研文档
- **data-model.md**: 数据模型设计
- **quickstart.md**: 快速开始指南
- **checklists/**: 验收清单
