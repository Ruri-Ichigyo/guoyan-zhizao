## 项目特性

### 核心功能

- 智能识别：基于 DenseNet121 的果蔬分类，支持 60+ 品类
- 质量分级：A/B/C 三级质量评估系统
- 多源接入：支持图像上传、实时摄像头、移动应用
- 统计分析：实时统计、数据可视化、历史记录查询
- AI 助手：智能聊天对话，数据库查询助手

### 技术栈

- **前端**: Vue 3 + Element Plus + TypeScript
- **后端**: Rust (Axum + SQLx)
- **AI 服务**: Python (FastAPI + PyTorch)
- **数据库**: PostgreSQL 15
- **缓存**: Redis 7
- **容器化**: Docker + Docker Compose
