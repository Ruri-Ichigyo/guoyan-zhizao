## 🔄 使用方法

### 生成所有图表

```bash
./generate-diagrams.sh
```

### 生成特定图表

```bash
./generate-diagrams.sh sequence     # 序列图
./generate-diagrams.sh architecture # 架构图
./generate-diagrams.sh workflow     # 工作流图
./generate-diagrams.sh dataflow     # 数据流图
```

### 修改图表

1. 编辑对应的 `.puml` 源文件
2. 运行生成脚本更新图片
3. 提交代码时包含更新的图表
